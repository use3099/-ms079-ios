# 枫叶单机 · iOS 试玩版

Swift / SpriteKit 原生横屏单机原型，最低 iOS 15，支持 iPhone 和 iPad。

## 下载 IPA

打开本仓库 [Releases](https://github.com/use3099/-ms079-ios/releases)，在成功发布的版本中下载 `MaplePocket-unsigned.ipa`。IPA 未签名，请使用自己的签名工具签名安装。源码包不是安装包。

[Actions 构建状态](https://github.com/use3099/-ms079-ios/actions)。只有打包和校验成功后才会出现下载文件。

## 当前玩法

一张村落和林地地图、触屏移动 / 跳跃 / 攻击、两种怪物、升级、金币、药水、守林任务和本地自动存档。左下移动，右下跳跃和攻击（可长按）；击败 8 只怪后回小屋找守林人对话领奖。进度保存在本机，卸载会删除。

这是独立的玩法试玩客户端，使用临时绘制美术，**不是完整冒险岛 v079 移植版**。尚未接入原服务端，没有官方 WZ 资源、职业转职、背包装备和联机功能。

## 工程与验证

客户端工程在 `MaplePocket-iOS-source.zip` 中；仓库工作流会自动解压、生成 Xcode 工程、编译 arm64 真机 App 并打包。工作流包含对压缩包内旧版打包命令的修正，本地构建时需将 `lipo` 命令改为 `lipo "$APP/MaplePocket" -verify_arch arm64`。

构建 #1 中四项模拟器测试全部通过，覆盖升级、药水和任务、防止重复领奖、存档往返及损坏回退、平台碰撞。只修改打包配置时不重复玩法测试；更新源码包或手动运行工作流时会运行测试。尚未完成真机安装和触屏体验验证。
